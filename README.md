# 🎊 دعوتنامه عروسی

دعوتنامه عروسی محمد سجاد و زهرا با موسیقی خودکار

## ویژگی‌ها ✨
- 📮 پاکت متحرک
- 🎵 موسیقی خودکار وقتی پاکت باز شود
- 📱 طراحی واکنش‌گرا
- 🎨 رنگ‌های جذاب

## نحوه استفاده
1. `imageUrl` را با لینک تصویر دعوتنامه خود تغییر دهید
2. `musicUrl` را با لینک موسیقی دلخواه تغییر دهید
